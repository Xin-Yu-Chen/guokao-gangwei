# 2027 国考选岗助手

**输入你的专业、学历、意向地区，秒级模糊匹配所有可报的国考岗位。**
纯静态网页、免费、开源、无需登录、数据不上传。

## 在线使用

👉 **[点击打开选岗助手](https://xin-yu-chen.github.io/guokao-gangwei/)**

## 功能特性

- **专业模糊匹配（三级）**：支持专业名称、专业代码、专业大类匹配。依据《2027 年国考税务系统专业参考目录》把专业归入大类，对"岗位写大类、你是该大类下具体专业"的情况也能命中，并标注 **直接命中 / 大类命中 / 相近匹配**，宁多勿漏。
- **学历匹配**：按"仅限本科 / 大专或本科 / 本科及以上 / 本科或硕士"等要求自动判断你的学历是否可报。
- **多维筛选**：省份/城市、部门、关键词、政治面貌、基层工作年限、考试类别、机构层级、职位属性、职位分布、是否组织专业能力测试、招考人数、仅看税务、不要求服务基层项目等。
- **卡片化结果**：简约卡片展示核心信息，可展开查看该岗位的全部字段。
- **单岗位 Word 分析**：一键下载该岗位的报考分析（含专业匹配、完整信息、报考条件自检、重点提醒）。
- **导出 CSV**：把当前筛选结果导出为 Excel 可直接打开的表格（UTF-8 编码）。
- **收藏 / 多岗位对比 / 筛选条件分享链接**。
- **数据本地处理**：筛选在浏览器内完成，不收集任何个人信息。

## 数据来源

- 《中央机关及其直属机构考试录用公务员招考简章（全国职位表）》：共 **19,426** 个职位；
- 《2027 年国考税务系统专业参考目录》：53 个专业大类、830 个专业名称。

数据均为公开招考资料整理，专业目录的大类归类适用于全部岗位。

## 重要声明

- 本工具为**个人制作的非官方信息检索辅助**，与任何招录机关、官方机构无关。
- 专业匹配为模糊结果，专业名称、培养方向、研究生学科归属等以招录机关解释为准。
- 一切报考条件、专业认定与最终结果，**以国家公务员局官方公告及报名系统为准**。
- 请在合法合规前提下使用，报名前务必致电招录机关咨询电话核实。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架、无构建、无后端。
- 数据为静态 JSON（`docs/data/`），GitHub Pages 自动 gzip 传输，筛选在浏览器本地完成。
- 本地运行：在 `docs/` 目录执行 `python -m http.server 8000`，访问 `http://localhost:8000`（直接双击 index.html 无法加载数据）。
